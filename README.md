# System Administrator Career Portfolio - Joyce Anne L. Nieva

Stack: HTML5, CSS3, vanilla JavaScript (no build step, no database).

## How to run
1. Keep the profile photo `images 06.jpg` in the project root.
2. Double-click `index.html` (or use VS Code "Live Server").

## Structure
- index.html            - all 5 required sections (Home, Roles, Skills, Tools, About) + Linux terminal
- css/style.css         - pastel purple theme, responsive layout, frame effects
- js/translations.js    - English / Filipino text
- js/terminal.js        - simulated Linux command prompt
- js/main.js            - translator, navigation, cards, effects

## Features
Language switch (EN/FIL), interactive role cards, animated skill bars with filter,
copyable tool commands, simulated Linux terminal, 3D holographic picture frame,
sparkle cursor, mobile menu, reduced-motion support.

## Free hosting (for the website URL requirement)
Upload the folder to GitHub Pages or Netlify Drop.
